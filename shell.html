Audio Loudness Matcher

In-Browser RMS Gain Matching & Soft Clipping Engine

About This Project

Hello, this is a software that I created to make the leveling of audio easy. The main reason why I decided to do this was because of my own experience with leveling sound effects and whatnot by myself, so I thought I could make it a lot less time-consuming for the person.

How to Use

It's pretty straightforward. There are two files you can upload: a WAV or an MP3. The first upload is the setting point for the audio, while the other is the one you want to change to match that audio level. After both are uploaded,the file exports to your downloads folder. However the only save formats with the current release are WAV and MP3 so keep that in mind.
